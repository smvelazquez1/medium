# Psychic Mediumship — Steven Velazquez

Static rebuild of mediumstevenvelazquez.cargo.site, hosted on GitHub Pages.

- `index.html`: the card spread (home)
- `Psychic-Reading.html`, `Mediumship-Reading.html`, `About-Me.html`, `Reviews.html`
- `style.css`: all styling
- `images/`: every image, exported from Cargo

To edit text, open the page's `.html` file on GitHub, click the pencil, change the words between the `<p>` tags, and commit. The site updates within a minute or two.
